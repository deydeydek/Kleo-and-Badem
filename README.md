# Kleo and Badem: Leader–Follower Robotic Arms
Kleo is a hand-moved leader arm, and Badem is the follower arm that copies Kleo's movements using servos. I designed and built the project myself. I’m sharing the code and a PDF document about the building process and wiring. I retain the rights to my work, but you’re welcome to use it—please credit me and let me know.  I’m also open to feedback and suggestions—feel free to open an issue.
